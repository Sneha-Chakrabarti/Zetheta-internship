| Field | Value |

| Model | Frequentist 5-state HMM (full-series fit) |
| Fit data window | 2011-01-04 to 2025-06-27 |
| Fit seed / valid restarts | 57 / 2 of 20 |
| Simulation seed / paths / horizon | 42 / 5,000 / 252 trading days |

**The "2 of 20 valid restarts" line is not a footnote to skip.** It
means this specific model required discarding 18 of 20 random
initialisations because they converged to degenerate solutions (a state
occupying under 1% of observations) - a direct, quantified measure of
how fragile this particular fit is. A briefing that omits this number
is omitting the single most important caveat on everything above it.

## 4. Mandatory caveats (do not omit these for a cleaner narrative)

Populate this section from the project's own established findings, not
generically:

- **Regime identification from returns alone is weakly determined for
  this model class.** BIC analysis (Day 4) prefers 3 states to 5;
  cross-language validation (Day 14) independently confirms this by
  finding Python and R converge to different local optima on identical
  data. Treat the dominant-regime call as a probabilistic lean, not a
  certainty, in proportion to how close the top probabilities are.
- **The ensemble layer does not reliably outperform its best single
  member** (Day 9, checked via genuine out-of-fold cross-validation,
  not assumed). If this call draws on an ensembled probability rather
  than a single model's, say which combination method and whether it
  beat the best member on held-out data for THIS model family.
- **A reactive changepoint detector (BOCPD) cannot substitute for
  calendar-aware positioning ahead of a KNOWN scheduled event** (budget
  day, election result, central bank decision) - Day 12's election
  case study is the concrete demonstration. If a scheduled event falls
  within the horizon above, say so explicitly and do not rely on the
  Monte Carlo interval alone to cover it.
- **A tilt recommendation is only as trustworthy as the regime
  identification feeding it.** A correctly-designed, risk-adjusted tilt
  rule fed a mis-estimated regime characteristic is no better than a
  naive rule (Day 13's Post-Shock finding). State which tilt rule was
  used and why.
